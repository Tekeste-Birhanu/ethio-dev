# EthioDev

EthioDev helps beginner and junior Ethiopian developers find project opportunities, collaborate with teammates, and coordinate work in Collabspaces.

## Milestones

1. Project setup and requirements
2. Accounts and developer profiles
3. Opportunity posts
4. Discover and search
5. Private chat
6. Collabspaces and group chat
7. Collaboration requests and invitations
8. Shared taskboard
9. Release readiness
10. Production and deployment

See the [local development guide](docs/DEVELOPMENT.md), [implementation tasks](docs/TASKS.md), and product and technical docs in [docs/](docs/).
